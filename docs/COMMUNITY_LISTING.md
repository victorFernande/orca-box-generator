# Community listing

## Português

**Orca Box Studio — caixas e gabinetes paramétricos no OrcaSlicer**

Crie caixas com encaixe por pressão, dobradiça reforçada, tampa deslizante ou parafusos de canto. Adicione torres de PCB, divisórias, portas de painel e uma junta TPU. Interface offline em PT/EN com visualização WebGL2, editor de posição, animação da tampa e kit de calibração. Exporte STL/3MF ou transmita um pedido de importação para a mesa.

O projeto é MIT e usa Python+NumPy. Encaixes e impressão dependem de calibração. Print-in-place preserva a montagem na exportação e exige avaliação de pontes/suportes; não é anunciado como livre de suporte. A integração visual nativa e os resultados físicos continuam sujeitos à homologação.

## English

**Orca Box Studio — parametric boxes and enclosures inside OrcaSlicer**

Design snap-lid, rugged hinged, sliding-lid and screw-corner cases. Add PCB supports, partitions, panel cutouts and a TPU gasket. The offline PT/EN workspace includes a WebGL2 mesh preview, placement editor, lid animation and a compact fit kit. Export STL/3MF or transmit an import request to the current Plater.

MIT licensed, using Python and NumPy. Fit and printing require calibration. Captive print-in-place assemblies preserve their export pose and require bridging/support assessment; support-free printing is not promised. Native visual integration and physical performance remain subject to validation.
